# OWASP OKF Bundle
This project is an OKF (Open Knowledge Format) bundle of the OWASP Top Ten 2025 risks and the OWASP Cheat Sheet Series guidance for understanding application security risks and applying practical defenses.

Useful for humans and agents and adding to agentskills.

Point your agent at https://raw.githubusercontent.com/rabidgremlin/okf-owasp/refs/heads/main/okf-owasp/index.md or download the latest bundle .zip file from the releases section.
